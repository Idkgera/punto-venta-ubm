# Punto de Venta UBM
Proyecto académico Flask + SQLite con inicio de sesión, inventario, imágenes, ventas con modal, consultas y reportes.

## Ejecutar en Windows
1. Instalar Python 3.12.
2. Descomprimir el proyecto y abrir `INSTALAR_Y_EJECUTAR.bat`.
3. Abrir http://127.0.0.1:5000 si no se abre automáticamente.
4. Usuario inicial: `admin`; contraseña inicial: `Admin123!` (cambiarla desde el sistema).

Requisitos: Windows con Python 3.12 e internet solo para instalar dependencias por primera vez. Los datos se guardan en `instance/pos.sqlite3` y las imágenes en `uploads/`.

Incluye las ramas `main`, `development`, `qa` en el repositorio Git local, con cambios en backend, frontend y pruebas. Para publicar en GitHub, consulte `docs/GITHUB.md`.
