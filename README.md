Punto de Venta UBM
Proyecto académico Flask + SQLite con inicio de sesión, inventario, imágenes, ventas con modal, consultas y reportes.

Ejecutar en Windows
1. Instalar Python 3.12.
2. Descomprimir el proyecto y abrir `INSTALAR_Y_EJECUTAR.bat`.
3. Abrir http://127.0.0.1:5000 si no se abre automáticamente.
4. Usuario inicial: `admin`; contraseña inicial: `Admin123!` (cambiarla desde el sistema).
